# Редактор Силянок

«Редактор Силянок» — настільна програма для створення схем силянок, герданів, браслетів, сережок, кулонів та інших виробів із бісеру. Редактор підтримує звичайні й зміщені сітки, багатошарове малювання, перетворення фотографій у схеми, розрахунок матеріалів та підготовку файлів для друку.

Програма написана мовою Python із використанням PyQt6. Основний файл застосунку — `selanka.py`.

## Основні можливості

- світла та темна теми;
- повноекранний режим і масштабування полотна;
- рівна сітка, парний і непарний пейот, brick stitch та власний зсув рядків;
- форми виробу: прямокутник, трикутник, ромб, коло, пара сережок і підвіска;
- олівець, гумка, заливка, піпетка, лінія, фігури, текст і виділення;
- регульована товщина пензля;
- горизонтальна й вертикальна симетрія;
- копіювання, вставлення, поворот та дзеркальне відображення фрагментів;
- багатошаровий малюнок із видимістю, блокуванням і дублюванням шарів;
- завантаження та трансформація фонового ескізу;
- перетворення фотографії у схему з налаштуванням кількості кольорів;
- підрахунок намистин, запас матеріалів і власні коди кольорів;
- undo/redo, автозбереження та список останніх проєктів;
- експорт у PDF, PNG, JPG, SVG і текстову схему по рядах.

## Встановлення

Потрібен Python 3.10 або новіший.

У Windows відкрийте PowerShell у папці програми та виконайте:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install PyQt6
```

## Запуск

```powershell
python selanka.py
```

Файл `icon.ico` має знаходитися поряд із `selanka.py`.

## Створення проєкту

Натисніть **«Новий»** або `Ctrl+N`, після чого задайте:

1. назву проєкту;
2. тип виробу;
3. тип сітки;
4. форму полотна;
5. кількість рядків і стовпців.

Тип і розмір виробу можна змінити пізніше у вкладці **«Виріб»**.

## Інструменти малювання

- **Пензель** — малює вибраним кольором. Товщина задається на лівій панелі.
- **Гумка** — прибирає клітинки з поточного шару.
- **Заливка** — заповнює зв’язану область однакового кольору.
- **Піпетка** — вибирає колір із клітинки.
- **Лінія** — проводить пряму між двома точками.
- **Фігура** — створює прямокутник, заокруглений прямокутник, овал, трикутник, ромб, шестикутник, зірку або хрест.
- **Текст у сітку** — перетворює напис на кольорові клітинки. Після вибору інструмента клацніть початкову клітинку та введіть текст.
- **Виділення** — вибирає область для копіювання, вставлення, повороту або дзеркального відображення.
- **Зсув** — вручну вмикає або вимикає зсув окремого рядка на половину клітинки.

Кнопка **«Очистити полотно»** видаляє намистини з усіх шарів і завантажений ескіз. Перед очищенням програма завжди запитує підтвердження.

## Масовий зсув рядків

Кнопка **«Масовий зсув рядків…»** дозволяє швидко створювати зміщені схеми.

- **Перший зсунутий рядок** визначає, з якого рядка починається шаблон.
- **Пропускати рядків між зсунутими** визначає період повторення.
- Значення `1` зсуває кожен другий рядок.
- Значення `2` зсуває кожен третій рядок.
- Якщо вимкнути очищення попередніх зсувів, новий шаблон буде додано до наявного.

Масовий зсув можна скасувати через undo.

## Перетворення фотографії у схему

1. Відкрийте вкладку **«Малювання»**.
2. Натисніть **«Завантажити зображення»**.
3. За потреби перемістіть, масштабуйте або поверніть ескіз.
4. Кнопкою **«Вписати зображення у сітку»** можна автоматично підігнати його під полотно.
5. Натисніть **«Перетворити зображення у схему»**.

У вікні конвертації доступні:

- кнопки **«Менше»** та **«Більше»**;
- точне поле і повзунок кількості кольорів;
- живий попередній перегляд результату;
- отримана палітра кольорів;
- режим **«Автокольори з фото»** — програма створює наближену палітру з самого зображення;
- режим **«Найближчі зі швидкої палітри»** — кожна клітинка отримує найближчий доступний колір користувацької палітри.

Результат записується на поточний незаблокований шар. Після конвертації ескіз автоматично фіксується і стає напівпрозорим.

## Шари

Початковий проєкт містить шари **«Фон»**, **«Орнамент»**, **«Контур»** і **«Підказка / ескіз»**.

Для кожного шару можна:

- змінити назву;
- приховати або показати;
- заблокувати редагування;
- створити копію;
- видалити.

Малювання, вставлення тексту та конвертація фотографії виконуються на активному шарі.

## Кольори та матеріали

Швидка палітра містить десять кольорів. Лівий клік вибирає колір, правий — змінює його.

У вкладці **«Кольори»** показуються:

- код кольору;
- кількість намистин;
- кількість із запасом 10%;
- наявність у власних запасах.

Для кольору можна вказати власний код бісеру, назву, ціну, кількість у запасі та нотатку.

## Збереження проєктів

Проєкти зберігаються у форматі `.syl`. Поточна версія формату зберігає:

- метадані проєкту;
- тип і форму виробу;
- параметри сітки та зсуви рядків;
- усі шари;
- палітру й матеріали;
- фоновий ескіз та його трансформацію.

Старі файли `.syl` також підтримуються. Для відкритого проєкту кожні дві хвилини створюється резервна копія з суфіксом `.syl.autosave`.

## Експорт

- **PDF** — кольорова схема, назва, автор, дата, сторінки та легенда матеріалів.
- **PNG/JPG** — растрове зображення для публікації.
- **SVG** — векторний файл для якісного друку.
- **Текстова схема** — послідовність кольорів для кожного рядка, наприклад `3×A, 2×B, 5×C`.

PDF підтримує автоматичне розміщення на сторінці або заданий фізичний розмір клітинки.
